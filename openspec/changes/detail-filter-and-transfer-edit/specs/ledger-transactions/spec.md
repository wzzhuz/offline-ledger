# ledger-transactions Delta

## ADDED Requirements

### Requirement: 统计下钻携带查看周期

从统计页带筛选跳转明细 SHALL 按下钻瞬间的统计粒度注入时间范围，
MUST NOT 沿用「不带时间 = 全部记录」的明细页默认语义。

#### Scenario: 月度视图下钻

- **WHEN** 统计页按月查看 2026-11，点分类扇区 / 图例或排行任意一维
- **THEN** 明细筛选带 20261101~20261130，chip 显示「时间：2026-11（来自统计）」

#### Scenario: 年度与多年视图下钻

- **WHEN** 统计页按年查看 2026、或按多年查看近 5 年
- **THEN** 明细分别带该年 1/1~12/31，或近 5 年整段；无界视图不带时间

#### Scenario: 覆盖全部下钻入口且可清空

- **WHEN** 从分类一级 / 二级、饼图扇区 / 图例、排行分类 / 收款方 / 账户跳转
- **THEN** 七类入口共用同一跳转出口与同一周期快照；进明细后清空时间即回全部记录，
  切月与已有筛选条件不丢失

### Requirement: 编辑态账户按 id 精确回填

转账记录编辑 SHALL 按记录里的账户 id 精确显示转出 / 转入账户，
MUST NOT 因常用排序或归档状态静默替换账户。

#### Scenario: 冷门或归档账户仍可见

- **WHEN** 编辑一笔转账，其转出或转入账户是冷门账户或已归档账户
- **THEN** 该账户出现在可见候选里并标为选中；归档项附「（已归档）」标注

#### Scenario: 原账户已删除

- **WHEN** 记录引用的账户已被删除
- **THEN** 编辑页提示「原账户已删除，请重新指定」，保存前拦截，
  MUST NOT 静默兜底成常用账户

#### Scenario: 不改直接保存零变化

- **WHEN** 进入转账编辑后不改任何字段直接保存
- **THEN** 转出 / 转入账户字段与进入前完全一致
