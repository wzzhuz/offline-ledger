# 统计下钻周期与转账编辑账户精确回填

## 背景

使用者在 v0.2.25 实测发现两处：

1. 从统计页（分类扇区 / 图例、排行三维）带筛选跳明细后不带时间，只能看全部记录；
   统计页按月 / 按年 / 多年查看的周期上下文被丢掉。
2. 明细页进入转账记录编辑，转出或转入若不是常用账户被排序挤到后面（或已归档），
   显示的账户不是记录里实际的账户，存在被静默改账户的风险。

## 目标

- 下钻瞬间把统计页正在查看的周期固化成 `fromDate/toDate` 带进明细，chip 明示；
  明细页手工筛选「不带时间 = 全部记录」的既有语义不回退。
- 编辑态按 id 精确回填账户，排序只影响展示顺序；归档账户可见并标注，
  已删除账户显式拦截；「什么都没改直接保存」账户字段零变化。

## 范围

零改表（`AppDatabase.version = 5` 不变）、零新增 SQL 出口、不动规则引擎与备份 DTO。
