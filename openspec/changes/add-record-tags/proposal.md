# add-record-tags · 账单多标签

## 为什么

「转账给老婆」在本 App 里没有分类字段，分类也只回答「钱花在什么性质上」。
一羽记账从 Android v4.3.0 起支持 `#tag`，CSV 手册写明「标签，多个以英文逗号分隔，最多 8 个」；
Firefly III 把 budgets / categories / tags 并列为三类组织手段，一笔交易可挂多个标签；
随手记、鲨鱼记账也有标签筛选（鲨鱼官网未列，标为「有说法、未证实」）。
还有一档「快捷标签」其实是把词写进备注、靠关键词搜索，没有独立字段与统计，属伪标签。

分类是纵向互斥（一笔一个），标签是横向交叉（一笔多个），用来把散在不同分类里的账打包。
所以「人情支出 + 标签『给老婆』/『家用』/『爸妈』」是标答，不必再堆二级分类。

核查代码：`RecordEntity` 无任何标签字段；Firefly III 的 `tags` 列已解析进 `FireflyRow`，
但目前与 `notes` / `budget` 一起拼进 `note`，导入说明白纸黑字「本项目没有标签系统」。
`record_tags` 不存在，统计 SQL 只认 `EXPENSE / INCOME`，转账不设分类。

## 改什么

- **Q1A 关联表多标签**：`tags` 定义表 + `record_tags` 关联表（复合主键 + 双向外键 CASCADE）。
  不用单列逗号串（LIKE 误命中、改名要刷全表），不用备注 `#tag`（伪标签）。
- **Q2A 全链路**：记一笔多选、明细按标签筛选、明细行/详情显示标签、
  统计标签维度、标签管理页，以及备份 / CSV / Firefly / 回收站四条往返。
  Firefly `tags` MUST 真正落成标签，不再写进备注。
- **Q3A 独立管理页**：`tags` 路由 + 增删改名 / 排序 / 归档，预置「给老婆」「家用」「旅行」。
- **Q4A**：`AppDatabase version = 7 → 8`（本批目标为 **version 8**），`Migrations.ALL` 保持空数组，不注册迁移。
  使用者已明确「现在都是测试数据，不需要考虑升级迁移」；但本批 MUST 在交付时明说
  **覆盖安装会开库失败、必须先导出备份再卸载重装**。
- **Q5A 利息不动**：`收入 → 理财收益 → 利息`（id 33001）已预制且启用，
  预制分类清单零改动，本批只做标签。

## 不改什么

- 分类两级模型、`CategoryDisplay` 拼接契约、`colorHex`、统计按 `amountCents` 的口径
- 转账不设分类、CSV `duplicateKey()`、FF3 幂等键 `(FIREFLY_III, journal_id)`
- 账户复合匹配键 `(name, cardLast4)`、加密备份 DTO 的既有字段语义
- `LedgerTheme` 全局配色、`INTERNET` 权限（仍为零）、零新增第三方依赖
- `build.yml`（除新增静态检查的调用行外）、`Migrations.ALL` 空数组不变
- 7 个进行中 change 与 4 个已归档 change，一个不动

## 验收标准（由我拟，使用者回「按你拟的」放行）

1. 记一笔可一次选多个标签，编辑已有流水时回填、保存后关联表正确
2. 标签管理页可新建 / 改名 / 排序 / 归档；改名后历史流水标签同步变化、不产生重复标签
3. 明细可按标签筛选，行内与详情页显示标签 chips
4. 统计标签维度给「命中金额 / 笔数 / 相对条形」，**MUST NOT 硬算百分比**
   （多标签相加会超过总支出，给了反而误导）
5. 加密备份导出→恢复、CSV 导出→导入、Firefly 导入、删除→回收站恢复，四条链路标签都不丢
6. CSV 新增 `tags` 列（逗号分隔名字、最多 8 个），导出必带、旧文件缺列按空串兼容
7. Firefly `tags` 落成标签，备注不再出现标签串
8. `version = 8`、`Migrations.ALL` 为空、文档明示卸载重装；装前先导出
9. 分类仍互斥、转账仍无分类；「给老婆」标签能挂在转账上
10. 10 个静态检查全 PASS、双 CI 全绿、出 v0.2.54 包
11. 预制分类清单逐字段零改动（利息不动）

## 被否决的方案及原因

- **单列逗号串**（Q1B）：`LIKE '%家用%'` 会误命中「家用支出」，标签改名要刷全表
- **备注 `#tag`**（Q1C）：没有独立统计/筛选，是伪标签，且会污染 `note` 全文检索
- **注册 `MIGRATION_7_8`**（Q4B）：破「稳定版前冻结迁移」既有口径，当前只有测试数据
- **标签塞进分类树**：分类互斥语义会被破坏，统计口径唯一出口失守
- **标签统计硬算百分比**：多标签合计 > 100%，数字看着精确实则误导
- **本批顺手把「利息」提为一级**（Q5B/C）：使用者选 Q5A，不动
