# 第 13 批：洞察式统计页与分类管理信息补齐（v0.2.0）

## 对齐结论

### ① 要解决什么问题
把 BeeCount「把聚合数据翻译成结论」的设计优点吸收进 offline-ledger，但不照搬它的连接型能力。
统计页现在是「周期→币种→概览→环形→折线→资产线」顺次平铺，所有区块同权重、两行口径小字常驻、
环形图之后没有排行结论；分类管理页结构已在第 12 批修好，但差「支出/收入分段、每类笔数、点分类看流水」。
目标是**一卡一结论 + 管理页有信息价值**，同时不重犯「卡片堆叠到又要滑两屏」的坑。

### ② 改什么 / 不改什么
**改**：新增 4 条只读聚合 SQL（笔数 / 交易对方 Top / 支出账户 Top / 分类笔数）、纯 JVM `InsightData`、
统计页重排为「总结卡 → 分类洞察卡（Top5 排行 / 可切环形）→ 趋势卡 → 年度资产卡 → 口径入口」、
平均值计算说明弹窗、空状态引导、预算进度条进大卡、隐私模式（一键隐藏金额）、
分类管理支出/收入分段 + 每类笔数 + 分类详情下钻 + 编辑视图字段分组、
统计排行卡「分类 ›」短跳转、版本号 0.2.0、静态检查 marker 扩项、纯 JVM 单测、
活文档 §7.3 / §8 更新。**先归档 `polish-settings-pages` 再开本 change**（基线干净）。

**不改**：表结构 / 备份格式 / `schemaVersion` / 4 Tab 导航格数 / NavHost 路由图 /
既有 6 条聚合 SQL 与 `StatRules.SQL_STAT_RELEVANT` / 余额全量重算 / 金额整数分 /
明细四列网格 / 筛选跨 Tab 状态提升 / Manifest 权限 / `release.yml` /
已确认不做的云同步、AI/OCR、小组件、通知、多币种混算与汇率折算。

### ③ 关键约束
- 零表结构变更 → **覆盖安装即可，不用卸载**；零新增 Gradle 依赖、零新增权限、Manifest 仍无 `INTERNET`
- 所有新增聚合 MUST 带 `type IN ('EXPENSE','INCOME') AND excludeFromStats = 0`，
  按当前币种筛选，**严格不混算**；年度只返回聚合行，MUST NOT 全表加载
- 「一级合计 = 二级合计 = 总净支出」一致性警告 MUST 继续置顶显眼，不得为美观收掉
- 统一网格两半（左边界 + 行高量级 32–44dp）、可点区 ≥40dp、`FilterChip` 底色选中、
  无 `● ` 前缀、无浮动 `label`、无横滚列表、输入框只用 `heightIn(min)`
- 隐私模式只遮**显示**，MUST NOT 改数据、MUST NOT 进备份 DTO、MUST NOT 回退已加密的 JSON 备份
- 图表独立 Y 轴、竖轴数值、点数值、横屏容器、资产线不混算等既有约束一字不改
- 新增筛选/聚合字段时同步「查询 / state / UI / 单测」四处，避免第 11 批「改一处漏一处」
- 动手前先把根因与三级回退顺序写进 `design.md`；六个静态检查全过；推送单次 commit

### ④ 验收标准
1. CI 全绿且 Actions 能查到；版本号 0.2.0、制品名带短 sha
2. **GIVEN** 某月含 12 笔支出 **WHEN** 打开统计 **THEN** 总结卡显示总计、笔数 12、日均 = 总计 ÷ 天数，点「平均值」弹出计算过程
3. **GIVEN** 多个分类与交易对方 **WHEN** 查看分类洞察卡 **THEN** 默认 Top5 排行（金额 + 占比条 + 百分比），可切回环形图，点排行项进入该分类明细
4. **GIVEN** 开启隐藏金额 **THEN** 统计 / 明细 / 资产页金额显示 `****`，数据不变，重启后偏好保留
5. **GIVEN** 某周期无任何流水 **THEN** 显示空状态引导（切月 / 切视图），不清空用户已设筛选
6. **GIVEN** 分类管理有支出与收入两类 **WHEN** 切换分段 **THEN** 只显示该类，每行去掉「（支出）」重复后缀并显示笔数（一级含二级合计）
7. **GIVEN** 点某个分类行 **THEN** 显示该分类近期流水（带 LIMIT），不全量加载
8. **GIVEN** 归档本批 **WHEN** 校验 specs **THEN** MODIFIED 按标题整块替换、无两份矛盾表述
9. 远端按最终 commit sha 逐文件比对 PASS、无 `diag/` 残留、无 token 明文

### ⑤ 被否决的方案
- 照搬 BeeCount 的 5 种同步 / 共享账本 / 账号 / AI / OCR / 语音 / 截图 / 小组件 / 通知 → 破第一条铁律与「永久不做」清单
- 引入 `beecount_ui` 式组件库或图表依赖 → 零新增依赖基线，且 Compose 版本风险
- 34dp 彩色分类图标目录 → 第 4 批刚因「6~7 色一眼不清晰」统一中性单色圆，照搬即回退
- 把统计页做成「所有卡片全堆在一屏」→ 会重犯筛选面板「要滑两屏」；改为固定顶部 + 四张卡 + 口径收纳
- 只追加 ADDED 不改「统计页落地月年切换与三种图表」等封闭描述 → 指南 §5 规格腐烂
- 隐私模式做成第 5 个 Tab 或全局静态变量 → 改导航 / Compose 不重组；用 `CompositionLocalProvider` + SharedPreferences 监听
- 分类管理改网格卡片 `_CategoryGridView` → 10 一级 + 20 二级时回到卡片堆叠
- 允许无账户流水 / 改既有 6 条聚合 SQL / 跨币种汇总 → 违反金额与统计铁律

**影响模块**：`reporting-ui`（主）、`category-stats`（主）、`privacy-security`（隐私模式）、
`build-and-ci`（静态检查与版本）、`money-precision` / `ledger-transactions` / `backup-restore` 只读。
**不与三条铁律或「已确认不做」冲突。**
