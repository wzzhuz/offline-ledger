## MODIFIED Requirements

### Requirement: 明细页默认时间范围语义
无任何筛选条件时，系统 MUST 按用户选择的周期粒度（月 / 年）只显示当前月 / 当前年，
且顶部标题 MUST 与列表范围一致；存在任意筛选条件且未设置时间段时，系统 MUST 显示全部时间的命中记录；
显式时间段与统计页下钻带入的周期 MUST 优先于默认粒度。
周期粒度切换 MUST NOT 清空其它筛选条件；月份条 MUST 仅作定位锚点、MUST NOT 注入月份过滤。

#### Scenario: 刚进入明细页
- **WHEN** 用户首次进入明细页或清空筛选
- **THEN** 标题显示当前月（或当前年），列表只包含该周期的记录

#### Scenario: 有筛选但无时间段
- **WHEN** 用户设置了分类 / 账户 / 对方等筛选、时间范围留空
- **THEN** 列表显示全部时间的命中记录，摘要明示「全部记录」与命中数

#### Scenario: 统计下钻
- **WHEN** 用户从统计页按分类 / 对方 / 账户下钻
- **THEN** 明细页沿用下钻瞬间的月 / 年 / 多年周期，不受默认粒度影响

### Requirement: 交易记录查看与编辑入口
点击一条记录 MUST 直接进入只读详情页；详情页 MUST 提供进入编辑、删除、报销 / 退款的一步入口，
删除与报销 MUST 保留二次确认与末尾重算。编辑态 MUST 把本记录引用的账户与交易对方置于候选最前，
且 MUST NOT 因排序改变选中项或静默改写账户。

#### Scenario: 查看并编辑
- **WHEN** 用户点击记录后点右上锁图标
- **THEN** 进入编辑态，字段按 id 精确回填，转出 / 转入账户显示在候选最前

#### Scenario: 不改直接保存
- **WHEN** 用户进入转账编辑、不修改任何字段并保存
- **THEN** 转出 / 转入账户与保存前完全一致

### Requirement: 切换月份或年份时列表默认刷新
切换查看周期 MUST 触发列表重新取数，标题与列表范围 MUST 同步；
系统 MUST NOT 用「记录尚未加载，继续下滑后再点一次」之类的提示把刷新责任转嫁给用户。
在全部时间模式下，月份仍 MUST 只作定位锚点、MUST NOT 注入月份过滤。
切月 MUST NOT 清空任何已设置的筛选条件。

#### Scenario: 月粒度切月
- **WHEN** 无筛选、月粒度下点左 / 右箭头或从年月选择器跳到另一月
- **THEN** 标题与列表立即变为该月，无需用户再点一次或先下滑

#### Scenario: 全部时间模式切月
- **WHEN** 有筛选且未设时间段时切月
- **THEN** 列表仍是全部时间的命中记录，并定位到目标月首条附近

#### Scenario: 目标月无记录
- **WHEN** 切到的月份没有任何命中记录
- **THEN** 列表为空且标题显示该月，MUST NOT 提示「尚未加载」

### Requirement: 周期粒度切换不独占一行
「月 / 年」粒度切换 MUST 与月份 / 年份标题处于同一行，MUST NOT 独立占据第二行；
标题 MUST 单行显示，MUST NOT 因挤压与相邻控件重叠。

### Requirement: 详情页消费系统返回手势
详情页打开时，系统返回（含全面屏左滑返回）MUST 被内部页消费并回到明细列表，
MUST NOT 直接退出应用；顶部关闭图标与「返回列表」按钮 MUST 走同一返回出口。
系统返回 MUST NOT 接管返回动画、MUST NOT 拦截 predictive back 预览。

#### Scenario: 全面屏左滑返回
- **WHEN** 用户在只读详情页从左边缘右滑 / 触发系统返回
- **THEN** 回到明细列表，应用保持在前台

### Requirement: 顶部月概览显示语义
明细页顶部「支出 / 收入 / 结余」月概览 MUST 仅在「无任何筛选条件、月粒度、单月窄视图」时显示；
年粒度、全部时间、显式时间段、统计下钻或任意筛选条件下，系统 MUST NOT 显示该组数字，
MUST 只保留 timeSummary() 的范围说明与筛选入口。
系统 MUST NOT 为隐藏态新增按范围的聚合查询，MUST NOT 把统计页数字并列搬入，
隐藏后 MUST NOT 留下空白占位；日头合计在跨范围态 MUST NOT 显示错月或 0 值。

#### Scenario: 统计下钻到别的月份
- **WHEN** 明细页停在 11 月、统计页查看 10 月并下钻进入明细
- **THEN** 列表为 10 月记录，顶部不出现 11 月的支出 / 结余数字，范围说明写明「时间：2026-10（来自统计）」

#### Scenario: 有筛选无时间段
- **WHEN** 用户设置筛选条件、时间范围留空
- **THEN** 顶部不显示月概览数字，范围说明明示「全部记录」与命中数

#### Scenario: 清空筛选
- **WHEN** 用户清空全部筛选回到默认月粒度
- **THEN** 顶部恢复显示当前月的支出 / 收入 / 结余
