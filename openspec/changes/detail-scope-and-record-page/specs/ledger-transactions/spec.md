## MODIFIED Requirements

### Requirement: 明细页默认时间范围语义
无任何筛选条件时，系统 MUST 按用户选择的周期粒度（月 / 年）只显示当前月 / 当前年，
且顶部标题 MUST 与列表范围一致；存在任意筛选条件且未设置时间段时，系统 MUST 显示全部时间的命中记录；
显式时间段与统计页下钻带入的周期 MUST 优先于默认粒度。
周期粒度切换 MUST NOT 清空其它筛选条件；月份条 MUST 仅作定位锚点、MUST NOT 注入月份过滤。

#### Scenario: 刚进入明细页
- **WHEN** 用户首次进入明细页或清空筛选
- **THEN** 标题显示当前月（或当前年），列表只包含该周期的记录

#### Scenario: 有筛选但无时间段
- **WHEN** 用户设置了分类 / 账户 / 对方等筛选、时间范围留空
- **THEN** 列表显示全部时间的命中记录，摘要明示「全部记录」与命中数

#### Scenario: 统计下钻
- **WHEN** 用户从统计页按分类 / 对方 / 账户下钻
- **THEN** 明细页沿用下钻瞬间的月 / 年 / 多年周期，不受默认粒度影响

### Requirement: 交易记录查看与编辑入口
点击一条记录 MUST 直接进入只读详情页；详情页 MUST 提供进入编辑、删除、报销 / 退款的一步入口，
删除与报销 MUST 保留二次确认与末尾重算。编辑态 MUST 把本记录引用的账户与交易对方置于候选最前，
且 MUST NOT 因排序改变选中项或静默改写账户。

#### Scenario: 查看并编辑
- **WHEN** 用户点击记录后点右上锁图标
- **THEN** 进入编辑态，字段按 id 精确回填，转出 / 转入账户显示在候选最前

#### Scenario: 不改直接保存
- **WHEN** 用户进入转账编辑、不修改任何字段并保存
- **THEN** 转出 / 转入账户与保存前完全一致
