# 第 45 批：默认周期视图、编辑态置顶与交易详情页

## Why
- 明细页「不带时间」在 v0.2.24 被全局设成全部记录，导致标题仍写当前月、列表却滚到别月，语义不一致；无筛选时用户只想看当前周期。
- 转账编辑里不常用 / 已归档账户排在后面，虽然 v0.2.26 已按 id 精确回填，但视觉上仍难找。
- 查看一条记录要「弹窗 → 再选编辑」两跳，删除 / 报销也藏在第二层，操作繁琐。

## What Changes
- **BREAKING（行为）**：无任何筛选条件时，列表按顶部粒度收窄到当前月或当前年；有筛选条件且未设时间段时看全部时间；显式时间段与统计下钻不受影响。
- 编辑态把本记录引用的账户（转出 / 转入）与交易对方置顶。
- 点击记录直接进只读详情页；右上锁切编辑、删除图标、报销 / 退款操作区一步到位。

## Capabilities
- `ledger-transactions`：默认周期语义、详情页只读 / 编辑分层。

## Impact
- 零改表（`AppDatabase.version = 5` 不变）→ 覆盖安装。
- 不动 DAO / SQL 出口 / 统计口径 / 备份 DTO / 规则引擎 / 二次确认与末尾重算。
