# backup-restore Delta（第 51 批）

## MODIFIED Requirements

### Requirement: 覆盖导入前二次确认与口径明确

覆盖导入前 SHALL 二次确认并明确提示「将全量替换现有全部数据」。v2 SHALL 把预置账户/分类的
去重规则定义为**全量替换**：先清空 `categories` 再按父先子后整表插回，
MUST NOT 按 id 增量合并、MUST NOT 按名称重映射、MUST NOT 只恢复流水而丢弃分类表。
分类 id 只是主键、不含语义，整表搬运与具体数值无关。

#### Scenario: 旧版备份导入 v0.2.34

- **GIVEN** 备份里的分类 id 属于旧编号体系（手工分类曾从 1502 起）
- **WHEN** 在全新安装后执行覆盖导入
- **THEN** 不出现 id 冲突或关联错乱（整表替换、备份内自洽）
- **AND** 旧分类表整体覆盖新版预制清单，新清单不生效
- **AND** 装包说明 MUST 写明「恢复标准清单 = 全新安装且不导入旧备份」

**理由**：旧备份手工 id 数值区间与新版二级段 `1001..` 重叠；只要保持整表替换就安全，
一旦改成增量合并即会撞号。故把「必须整表替换」钉死为可核查条款。
