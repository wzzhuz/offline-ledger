# Delta for 页面、性能与范围

## MODIFIED Requirements

### Requirement: 四 Tab 骨架一次成型

系统 SHALL 保持恰好 4 个底部 Tab（明细 / 资产 / 统计 / 设置）与中央 `+` FAB。
资产页 SHALL 展示真实净资产看板、总资产 / 总负债、账户分组与对账入口；
统计页在阶段 4 落地前 SHALL 显示明确标注「阶段 4」的占位内容。
系统 MUST NOT 因某阶段内容为空而隐藏 Tab、临时把设置移到第 5 格，
也 MUST NOT 把核对视图做成第 5 个 Tab（核对视图 SHALL 为资产页内 Dialog）。

#### Scenario: 打开资产页

- **GIVEN** 应用已记入若干流水与账户
- **WHEN** 点底部「资产」
- **THEN** 显示净资产、总资产、总负债与账户分组
- **AND** 每个账户有「详情」与「对账」入口
- **AND** 底部导航仍是 4 个 Tab

#### Scenario: 打开统计页

- **GIVEN** 阶段 3 版本
- **WHEN** 点底部「统计」
- **THEN** 显示「统计报表 · 阶段 4」占位说明
- **AND** 导航结构不变

**理由**：阶段 2 的原文写「点资产 → 显示『资产看板 · 阶段 3』占位说明」，
阶段 3 落地后会与实际行为相反。MODIFIED 把「一次成型的骨架」保留为长期约束，
把占位 Scenario 换成真实资产页行为；统计页仍占位但不再绑定具体阶段版本号。
这正是阶段 2 归档 `design.md` 记录的规格债，必须按标题替换而非追加 ADDED。
