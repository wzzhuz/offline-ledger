## 触发与修订缘由

第 68 批（v0.2.48）交付真机后，使用者明确反馈「改完更丑了，可能我描述的不够
详细，我们之间理解存在偏差」，并给出 5 条具体纠正。**第 68 批的三处判断是跑偏

当成「参考一羽」，实际是照着自己的推断加戏。本批逐条撤回并按用户原意重做。

## 五项对齐结论（使用者回 Q1A Q2A Q3A Q4B Q5B Q6A + 验收按我拟的）

1. **要解决什么问题**：撤回第 68 批跑偏三处，按 5 条纠正重做统计页；

     分类卡里的三维度 chip；一级行「⌄」展开小类；

     图例列表承担 TopN（图标 + 名称 + 百分比 + ¥金额 + 灰色长条）；
     收款方 / 账户退回独立卡片、默认折叠、左上角单标签切换；

     全 23 个含 Card / background 的文件观感都会变，如实登记，不假装零回归。

     （两个活跃 change 正在改明细侧，不碰它们），统计不再向明细 VM 注入状态。
   - 零改表 → v0.2.48 可直接覆盖安装，不用卸载。
4. **验收标准（由我拟，非使用者逐字给出，可直接改砍补）**
   1. 统计页顶部为原有白底「统计」+ 月度 / 年度 / 多年 + 币种切换，
      **无蓝底块、无「分析 / 概览」Tab**。
   2. 分类占比卡左上角只有一个「大类 ⇄ / 小类 ⇄」标签，点一下来回切；
      卡内无三维度 chip、无一级「⌄」展开、无「看小类」以外的二级入口。
   3. 图例每行含彩色分类图标、名称、百分比、¥金额、灰色长条；
      长条长度与百分比一致，五行金额合计 = 环中心净支出。

      左上角一个「收款方 ⇄ 账户」标签切换，无一排 chip；只读不跳转。
   5. 点扇区或图例行弹出**底部 sheet**，按明细页行样式展示该分类流水

      最多 100 条、按日期倒序，**不切 Tab、不写明细 VM**。
   6. 全局卡片为纯白、页面底为浅蓝灰，红 = 支出 / 绿 = 收入语义不变；
      一羽式清新感由配色而非新增装饰提供。
   7. 合计一致性警告仍置顶显眼；「分类管理 ›」仍在占比卡标题右侧；
      既有常驻点数值、竖向引导线、横屏放大、趋势四项摘要零回归。
   8. 八个静态检查 + 新增检查全 PASS，push CI 与出包 CI 全绿；
      §8 新增真机待验全部留 `[ ]`，既有项整体继承，CI 全绿不替代观感。
   9. 覆盖安装（v0.2.48 → v0.2.49）不丢数据、不升表。
