# 提案：统计页参考一羽记账优化（第 68 批 / v0.2.48）

## 触发

使用者给出 5 张真机截图：图 1–4 为一羽记账统计相关页（分类聚合页、小类占比、
大类占比、分析页），图 5 为本 App 统计页；原话「统计页面也参考一羽记账进行一下
优化」「1.分类排行考虑合入分类占比 2.其他页面参考一羽」。

## 问题

本 App 统计页是「白底标题 + 多行 Switcher + 小结 / 趋势 / 占比 / 排行四张各自
独立卡片」，与一羽的「蓝底身份区 + 层级 Tab + 单卡内环形与图例列表」相比，
信息层级平铺、占比与排行割裂、图例缺少百分比与金额、趋势点选反馈弱。

## 五项对齐结论（使用者回「按你拟的」= Q1A Q2A Q3A Q4A + 验收按我拟的）

1. **要解决什么问题**：按一羽观感重排统计页，重点把分类排行合入分类占比。
2. **改什么 / 不改什么**
   - 改：统计页蓝底 TopBar +「分析 / 概览」Tab；小结卡进度条化；趋势卡补点选气泡
     与四项摘要；占比卡与排行卡合为**一张**「环 + 一羽式图例列表」，收款方 /
     账户维度收进卡内 chip；统计页分类标识放行彩色 Tabler 图标。
   - 不改：统计口径（净支出 = 毛支出 − SETTLEMENT）、既有 6 条收支聚合 SQL、
     `colorHex`、三级下钻路径与 7 类下钻共用 `StatsDrillRange`、合计一致性警告置顶、
     图例整行可点 ≥40dp、点数值常驻与横屏放大、分类管理短跳转、按当前币种不跨币种
     混算、`version = 7`、底部 4 Tab、不新增分类聚合页、不引入收支类型切换。
3. **关键约束**
   - Q1A 显式 MODIFIED 整块替换 3 条基线 MUST NOT「两卡不得合并」条文，并撤回
     活文档 §7.3「合并 = 一屏硬塞」的旧结论：一羽式是**同卡上下排布**，不是
     第 13 批那种互斥切换 chip。
   - Q2A 显式 MODIFIED 3 条基线「统计页 SHALL 中性圆 + 首字」条文，
     彩色范围扩为「分类管理三页 + 两个全量选择器 + 统计页分类占比图例」；
     记一笔快捷栏、明细列表行、账户详情仍中性圆 + 首字。
   - 与 `detail-filter-and-transfer-edit`（统计下钻携带查看周期）、
     `detail-scope-and-record-page`、`add-discount-and-fee`（统计按实付
     `amountCents`）交叉：合卡时 MUST NOT 顺手删掉扇区 / 图例 / 排行各维度 /
     展开子项的同一下钻回调（活文档 §7.12）。
   - 零改表、零新增 Gradle 依赖、零 `INTERNET`、零新增聚合 SQL 出口；
     v0.2.47 可直接覆盖安装。
4. **验收标准（由我拟，非使用者逐字给出，可直接改砍补）**
   1. 统计页顶部为蓝底身份区，含月份与「分析 / 概览」两个**真实可切**Tab；
      概览显示小结 + 合体卡，分析显示全部卡片。
   2. 小结卡收入 / 支出 / 结余三行对齐，支出行有红色进度条，数字与既有口径一致。
   3. 趋势卡点选后出现蓝色圆角气泡汇总，卡底有「笔数 / 日均 / 单日最高 / 峰值日」
      四项摘要；既有常驻点数值、竖向引导线、横屏放大零回归。
   4. 占比与排行为**一张卡**；环中心写「净支出 ¥X」；图例列表每行含彩色分类图标
      （或中性圆兜底）、名称、百分比、金额，整行可点且触摸区 ≥40dp。
   5. 分类维度保留「按大类 / 按小类」切换；维度 chip 可切「分类 / 收款方 / 账户」，
      三者都接既有下钻回调；分类维度图例一级项可展开二级。
   6. 合计不一致警告仍置顶显眼；「分类管理 ›」仍在合体卡标题右侧。
   7. 彩色 Tabler 只进统计占比图例，记一笔 / 明细 / 账户详情仍中性圆 + 首字；
      `colorHex` 与统计扇区色板零改动。
   8. 六个静态检查 + 新增检查全 PASS，push CI 与出包 CI 全绿；
      §8 新增真机待验全部留 `[ ]`，既有项整体继承，CI 全绿不替代观感。
   9. 覆盖安装（v0.2.47 → v0.2.48）不丢数据、不升表。
5. **被否决的方案及原因**
   - 第 13 批式「用 chip 让环与排行二选一显示」：使用者第 14 批已推翻，且一羽
     不是这种交互。
   - 改净支出口径 / 新增分类笔数聚合 SQL：会撞「既有聚合 SQL 不改」，本批图例
     不显示「(N条)」，如实登记。
   - 环外悬浮百分比文字：项目 `DonutChart` 文件头明令不用
     `DrawScope.drawText` / `TextMeasurer`，改由图例列表承载百分比。
   - 1:1 砍掉收款方 / 账户排行：会丢既有下钻维度。
   - 高饱和 6~7 跳色、`colorHex` 开放用户可配、跨币种混算、
     AlertDialog 遮挡趋势点数值：均为基线明禁。

## 分级判定

改变多条基线 Requirement + 改变系统行为 + 与 3 个活跃 change 交叉 →
**新建 change `polish-stats-like-yiyu`**。不动 3 个已归档 change，
也不混进 6 个进行中 change。
